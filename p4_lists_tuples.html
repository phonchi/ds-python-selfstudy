PART 01 · 簡介

容器與序列：不只能裝一個值

🎯 這一章的終點：學完 list 和 tuple，你就能親手寫出經典猜數字遊戲「1A2B」——先把基礎練熟，後面遊戲一次派上用場！

到目前為止，一個變數只能存一個值。這一章要介紹 list（串列）和 tuple（元組）——想像成一整排置物櫃：每一格（元素）都有自己的櫃號（索引），你可以直接憑號碼打開任何一格，不用從頭一格一格找起。像這樣可以「裝進」其他物件的資料型別，就稱為 容器（containers）；容器自己也帶了一套專屬工具，叫做 方法（methods），用來操作櫃子裡的東西。

list 和 tuple 都屬於 序列（sequence）資料型別——代表有序的項目集合，就像置物櫃是按號碼排好的，順序不會亂跑。它們與 string、以及 range() 回傳的 range 物件享有相同的特性：都可以用索引、切片、for 迴圈、len()、以及 in / not in 運算子來操作。

👨‍⚕️ 學習心法

串列最重要的兩個觀念是本章的核心：索引與切片如何精確取值，以及變數其實只是「參照」——這會影響串列被複製、被傳進函數時的行為。先把這兩個心法建立起來，後面所有操作都會豁然開朗。

PART 02 · 索引

使用索引取出串列中的單一元素

在 string 中，值是字元；在 list 中，它們可以是任何型別。用逗號分隔的值放進中括號 [ ] 就能建立 list；空的中括號 [] 建立空串列。

subjects = ['邏輯與集合', '離散數學', '初等數論', '基礎數學'] print(subjects[0]) # 邏輯與集合，索引從 0 開始！ print(subjects[3]) # 基礎數學
⚠ 常見錯誤

如果索引超過串列長度，例如 subjects[4]（這個串列只有索引 0~3），Python 會丟出 IndexError——這是一種執行時錯誤。另外要小心區分：中括號用來建立串列（[1,2,3]）還是用來索引已存在的串列（subjects[0]），語法看起來很像但意義完全不同！

list 的元素不必是相同型別，甚至可以包含另一個 list（巢狀串列），這時要用多重索引來取值：

spam = ['spam', 2.0, 5, [10, 20]] spam[3][1] # 20 —— 第一個索引選外層 list，第二個索引選內層 list spam[3] # [10, 20] —— 只用一個索引會取出整個內層 list

負數索引與 len()

索引也可以用負整數：-1 代表 list 的最後一個元素，-2 代表倒數第二個，依此類推。len() 函數會回傳串列中的元素個數（就像它能算字串的字元數一樣）。

subjects = ['邏輯與集合', '離散數學', '初等數論', '基礎數學'] print(subjects[-1]) # 基礎數學 —— 最後一個 print(subjects[-2]) # 初等數論 —— 倒數第二個 len(subjects) # 4

PART 03 · 切片

使用切片從串列中取出子串列

索引可以取出單一值，切片（slicing）則可以取出多個值，並回傳一個全新的 list。語法是 list[start:stop:step]：從索引 start 開始，一路取到 stop（但不包含 stop），step 是間隔（預設 1，可省略）。

省略 start 等於從 0（或最尾端）開始；省略 stop 等於取到底；step 為負數時會反向取值——list[::-1] 就是把整個串列反轉的經典寫法！

🧪 互動：切片試算器

下面固定示範串列 spam = ['cat', 'bat', 'rat', 'elephant']，每個格子上方是正索引、下方是負索引。在三個欄位輸入 start / stop / step（可留空），格子會即時高亮出被切到的元素，橘色數字代表該元素在結果中的順序。

🧪 SANDBOX · 切片試算器

用 del 從串列中移除值

del 敘述可以刪除 list 中指定索引處的值，後面的元素會自動往前移動；也可以搭配切片一次刪除多個相鄰元素：

t = ['a', 'b', 'c', 'd', 'e'] del t[1] # t 變成 ['a', 'c', 'd', 'e'] del t[1:3] # t 變成 ['a', 'e']，一次刪除索引 1、2
PART 04 · 修改元素

用索引更改串列中的值

與 string 不同，list 是可變的（mutable）：你可以重新指定串列中的項目。當中括號操作符出現在指派敘述的左邊，就代表要修改該索引處的元素，這個動作稱為項目指派（item assignment）：

numbers = [17, 123, 42, 7] numbers[1] = 5 numbers # [17, 5, 42, 7] —— 原本的 123 被 5 取代
name = 'pokemon tcg pocket' name[7] = 'a' # TypeError: 'str' object does not support item assignment
⚠ string 做不到！

string 是不可變（immutable）的，就算只是想把 name 裡的一個字元換掉，Python 也會丟出 TypeError。這是 list 與 string 最關鍵的差異，後面「序列型別家族」會整理成表格比較。

PART 05 · 串接與重複

串接 List 與複製 List

串列可以像字串一樣串接（concatenation）和重複（repetition）。+ 運算子把兩個串列合併成一個新串列；* 運算子搭配整數值可以重複整個串列。

運算式結果
[1, 2, 3] + ['A', 'B', 'C'][1, 2, 3, 'A', 'B', 'C']
['X', 'Y', 'Z'] * 3['X','Y','Z','X','Y','Z','X','Y','Z']
💡 提醒

+ 不會把數字相加、也不會重新排序項目，它只是單純把兩個串列的元素依序接在一起，產生一個全新的串列（原本兩個串列不會被改變）。

PART 06 · 走訪

List 走訪：for、range()、enumerate()

for 迴圈的本質，就是沿著置物櫃排成的走廊，從第一格走到最後一格，每經過一格就把裡面的東西拿出來做點事——這種「一項一項處理」的動作稱為逐項迭代。range(4) 回傳的其實也是一個序列，Python 會把它當成類似 [0, 1, 2, 3] 的東西：

for subject in subjects: # 只需要讀取元素時，直接走訪串列最簡潔 print(subject)

如果需要索引來寫入或更新元素，常見做法是搭配 range(len(...))：

numbers = [17, 5, 42, 7] for i in range(len(numbers)): numbers[i] = numbers[i] ** 2 # [289, 25, 1764, 49]

更常見、更 Python 風格的寫法是用 enumerate()——它每次迴圈會同時回傳索引和項目本身：

for i, number in enumerate(numbers): print(i, number) numbers[i] = number ** 2

in 與 not in 運算子

用 in 和 not in 可以判斷某個值是否存在於 list 中，結果是一個 Boolean：

print('hello' in ['hello', 'hi', 'haha', 'he']) # True print('國文' not in subjects) # True，subjects 沒有「國文」
PART 07 · 常見方法

list 的常見方法：append、insert、del、sort

方法（method）與函數相同，只是它是「對一個物件」呼叫，寫法是 物件.方法名()。append() 把新元素加到串列尾端；insert(索引, 值) 把元素插入到指定位置（原本在那之後的元素都會往右移一格）。

⚠ 回傳值是 None！

append()、insert()、sort() 都是就地修改（modify in-place）串列本身，回傳值是 None。千萬不要寫 t = t.append('d')——這會把 t 變成 None！正確寫法是直接呼叫 t.append('d')，串列會自動被改變。方法屬於單一資料型別：append() 是 list 的方法，不能用在 string 或 integer 上。

🎬 逐步執行下面這段程式，觀察 t 的內容與索引如何變化（黃色 = 受影響的元素，綠色 = 新加入的元素）：

t = ['bat', 'cat', 'rat'] t.append('elephant') t.insert(1, 'ant') del t[3] t.sort() # 預設遞增排序 t.sort(reverse=True) # 反向（遞減）排序 print(t)

extend() 呢？

extend() 會把另一個序列的所有元素逐一加到尾端，例如 color_names.extend(['藍色','紫色'])，相當於 color_names += ['藍色','紫色']。這跟 append() 把整個引數當成單一元素加入不同（下方測驗會考這個！）。

key=str.lower 排序

sort() 預設會把大寫字母排在小寫前面（依 ASCII 碼）。若想「不分大小寫」排序，可以用 spam.sort(key=str.lower)，讓 Python 排序時先把每個字串轉成小寫再比較。

PART 08 · 串列生成式

串列生成式：一行程式碼建立新串列

想像一個問題：如何做出一個包含 1~10 平方數的 list？傳統寫法要先建立空串列，再用 for 迴圈搭配 append()：

squares = [] for value in range(1, 11): squares.append(value ** 2) # squares = [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

串列生成式（list comprehension）把 for 迴圈和新元素的建立結合為一行，自動把每個新元素附加到串列中：

squares = [value ** 2 for value in range(1, 11)] # 一模一樣的結果：[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

還可以加上 if 子句來過濾元素，只保留符合條件的值——這裡示範只保留偶數：

list1 = [item for item in range(1, 11) if item % 2 == 0] # list1 = [2, 4, 6, 8, 10]
👨‍⚕️ 語法拆解

① 一個有意義的變數名稱存放新 list（如 squares）。② 中括號內先寫「要儲存的運算式」（value**2）。③ 接著寫 for 迴圈提供輸入值。注意 for 後面不需要冒號——語法和一般 for 迴圈不同！這也很像數學的集合建構式：$\{x^2 \mid x \in \{1,...,10\}\}$。

PART 09 · 序列型別

序列資料型別：可變 vs 不可變

list 並不是唯一表示有序值序列的資料型別。string、range 物件和 tuple 都共享序列的特性——都能索引、切片、放進 for 迴圈、搭配 len()，以及使用 in / not in（'a' in 'apple' 也成立！）。但它們在可變性上分成兩派：

型別可變性可修改元素？典型建構
list 串列可變 mutable可以（項目指派、append 等）[1, 2, 3]
tuple 元組不可變 immutable不行（TypeError）(1, 2, 3)
string 字串不可變 immutable不行（TypeError）'abc'
range 物件不可變 immutable不行range(3)
⚠ 重新指派 ≠ 修改

變數可以被覆寫成新的 tuple 或 string（name = name + '!'），但這不等於「修改現有的值」——這其實是建立了一個全新的物件，讓變數改指向它。因為不可變，tuple 沒有 sort()、reverse() 這類就地修改的方法；但可以用內建函數 sorted()、reversed()，它們接受任何序列並回傳一個新序列。

PART 10 · 元組

元組（tuple）與序列拆解

tuple 是一種與 list 類似的序列型別，可以儲存任何型別的值，並用整數索引。最關鍵的差異：tuple 是不可變的。雖然不是必要，但通常會用小括號 ( ) 把 tuple 包起來，方便一眼認出：

t = ('a', 'b', 'c', 'd', 'e') print(t[0]) # 'a'，索引用法跟 list 一樣 print(t[1:3]) # ('b', 'c')，切片也一樣可以用 t[0] = 'A' # TypeError！tuple 不能項目指派
⚠ 只有一個元素的 tuple

要建立只有一個元素的 tuple，結尾一定要加逗號：t1 = ('a',)。如果忘記逗號寫成 t3 = ('a')，Python 只會把它當成加了括號的字串，type(t3) 會是 str 而不是 tuple！另一種安全的寫法是用 tuple() 函數：tuple('a')。若 tuple() 的引數是序列（string、list、tuple），結果會是一個包含該序列所有元素的 tuple，例如 tuple('nsysu') 會拆成 5 個字元的 tuple。

序列拆解（unpacking）

可以把一個序列的元素，依序拆解賦值給多個以逗號分隔的變數——這也是上一章「多重指派」a, b = 1, 2 背後的真正原理：

student_tuple = ('Alice', [98, 85, 87]) first_name, grades = student_tuple print(first_name, grades) # Alice [98, 85, 87]

這種拆解技巧常用在函數需要回傳多個值的時候（函數其實是把多個值包成一個 tuple 回傳）：

def total_ave(grade): total = sum(grade) ave = total / len(grade) return total, ave # 回傳一個 tuple: (total, ave) total, ave = total_ave([85, 70, 100, 90]) # 345, 86.25

PART 11 · 參照

參照（reference）：變數不是盒子，是一張標籤

在 Python 中，變數儲存的是參照——也就是物件在記憶體中的位址（可以用 id() 查詢）。對不可變物件（整數、字串），這件事幾乎感覺不到，因為你永遠無法「修改」它，只能讓變數改指向新物件。但對可變list，這會產生一個關鍵後果：兩個變數可以同時指向同一個串列！

🎬 逐步執行，觀察 spam 和 cheese 這兩個標籤的關係：

按「單步 ▸」開始執行
spam = [0, 1, 2] cheese = spam # 複製「參照」，不是複製 list！ cheese[1] = 'Hello!' # 修改的是同一個 list print(spam) # spam 也被改變了！ clone = copy.copy(spam) # 真正複製一份新 list clone[0] = 99 # 只改到 clone，不影響 spam print(spam, clone)
▸按「單步 ▸」開始
輸出 Console
傳遞參照給函數

呼叫函數時，引數的值會被複製到參數變數中；對 list 來說，被複製的是參照的副本，兩者仍指向同一個串列：def eggs(p): p.append('Hello')，呼叫 eggs(spam) 後 spam 也會被改變！

copy() vs deepcopy()

copy.copy() 複製一份新的串列（但若串列裡還有子串列，內層仍共用參照）。如果串列包含其他串列，要用 copy.deepcopy() 才能連內層也一併複製，得到完全獨立的物件。

👨‍⚕️ 就地修改小結

Python 的垃圾回收器會自動清除不再被任何變數參照的值，不需要手動管理記憶體。但也因為如此：若兩個變數參照同一個 list，其中一個被就地修改（append、sort、項目指派…），另一個也會跟著改變。切片則是例外——切片會建立一個全新的 list 物件，不會共用參照。

insert(i, x)在索引 i 插入元素就地修改，回傳 None
extend(seq)把另一序列逐一元素接到尾端相當於 list += seq
sort() / sort(reverse=True)就地排序（遞增／遞減）就地修改，回傳 None
sort(key=str.lower)不分大小寫排序key 指定排序前的轉換函數
del list[i]刪除指定索引的元素非方法，是敘述
len(list)元素個數序列型別通用
sorted(seq) / reversed(seq)回傳排序／反轉後的新序列不修改原序列，tuple/string 也能用

可變 vs 不可變、參照

觀念重點
list可變，可就地修改
tuple / string不可變，(x,) 建立單一元素 tuple
a = b（b 是 list）複製參照，a 和 b 指向同一個 list
copy.copy(b)複製出新的獨立 list（淺複製）
copy.deepcopy(b)連內層巢狀 list 都一併複製
