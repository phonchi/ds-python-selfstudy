PROLOGUE · 開場

引言：從「演算法」到「程式」

問題解決是電腦科學的核心，而你在解題過程中創造出的解決方案叫做演算法（algorithm）：一系列逐步的指令，只要完全照做，就能解決問題。演算法就像食譜或遊戲攻略——必須精確、清楚無歧義，而且要能在有限步驟內結束。

為了提高精確性，演算法通常先用虛擬碼（pseudocode）寫下來，再由程式設計（programming）轉換成電腦能執行的程式語言——例如本課程的主角 Python。

上一頁想清楚了「為什麼要學程式」，這一頁開始真的動手：把想法變成能跑的 Python 程式。而且 Python 正紅得誇張——它是目前全世界最受歡迎的程式語言之一，連近期 Excel 也加入了 Python 的支援，代表這個語言早就不只活在程式教室裡了。

範例：計算直角三角形斜邊

虛擬碼：① 輸入兩股長 a、b　② 令 hypotenuse = √(a² + b²)　③ 顯示斜邊長

Python：hypotenuse = (a**2 + b**2)**(1/2) —— 同一個演算法，換成電腦看得懂的寫法而已！

👨‍⚕️ 學習心法

程式設計的解題過程始於演算法的設計。先用虛擬碼想清楚每個子步驟，再翻譯成程式。執行程式前，先預測它會輸出什麼，再執行來驗證你的理解！

PART 01 · HELLO, PYTHON

Hello, Python：直譯器與第一行程式

Python 是目前全世界最受歡迎的程式語言之一，語法簡潔易讀，也是資料科學與 AI 領域的首選。它是一種直譯式語言：你輸入的指令由直譯器（interpreter）一行一行讀取並立即執行。

直譯器 Interpreter編譯器 Compiler
執行方式逐行讀取 → 立即執行先整份翻譯成機器碼 → 再執行
修改後直接重新執行需要重新編譯
代表語言PythonC / C++

一個指令（更正式的說法是敘述，statement）會叫直譯器做一件事。經典的第一支程式：

print('Hello, World！')

這一行藏了三個重要概念：

① print() 是內建函數——Python 預先定義好的操作，括號內放的是參數。
② 'Hello, World！' 是字串常數——固定不變的資料，用單引號 ' 或雙引號 " 包起來。
③ # 開頭的文字是註解——寫給人看的，電腦執行時直接忽略。

⚠ 常見疑問

印出來的結果不含引號！引號只是用來標示「字串的開始與結束」。另外 print('Hello', 'World!') 可以用逗號一次印多個值，中間自動以空格分隔。

PART 03 · 變數

變數：幫資料貼上「標籤」

把變數想像成貼在資料上的標籤。用指派敘述（=）把值存進變數：varName = 100。重要觀念：Python 中一切皆物件，變數其實是指向物件的「參考」——標籤可以隨時撕下來貼到別的物件上。

🎬 互動：變數是標籤，不是盒子本身

當變數被指派新值，舊值就會「被遺忘」，這叫覆寫。逐步執行，注意 spam 這個標籤如何從 'Hello' 移動到 'Goodbye'：

按「單步 ▸」開始執行
spam = 'Hello' # 'Hello' 是一個字串物件 print(spam) # spam 只是指向物件的標籤 spam = 'Goodbye' # 標籤移到新的物件上 print(spam)

與數學不同！

數學裡 x = 3 之後不會中途變成別的值；但程式裡 a = a + 1 完全合法——意思是「取出 a 現在的值，加 1，再把標籤貼到新結果上」。

動態型別

Python 宣告變數不必先說型別，同一個變數可以先存字串再存數字（動態型別，Dynamic Typing）。

PART 04 · 資料型別

資料型別與轉換

電腦為什麼要把資料分成 int、str 這些不同型別？因為型別搞混會直接出事——'16' + 1 會讓 Python 當場報錯，這種事故你在下面的 P05 除錯就會親眼看到。搞懂型別，才不會被這類地雷炸到。

Python 中每個值都有型別（type），可以用 type() 函數查詢。五個基本型別：

型別範例說明
int 整數5、-3、12_000可用底線分組大數字，更好讀
float 浮點數3.14、2e10帶小數點；2e10 是科學記號 = 20000000000.0
str 字串'characters'單引號或雙引號皆可
bool 布林值True / False注意大小寫！
complex 複數2+1j1 不能省略（j 不行，要寫 1j）

兩種型別轉換

隱式轉換 Python 自動把「較小」的型別轉成「較大」的以避免資料遺失：5 + 4.2 → 9.2（int 自動升級成 float）。順序是 complex > float > int > bool。

明確轉換 你手動呼叫轉換（cast）函數：int()、float()、str()。注意 int(3.9) 得到 3——是直接捨去小數，不是四捨五入！

PART 05 · 除錯

除錯：三種錯誤，三種對付法

學程式的過程中，大部分時間其實花在找出並修正錯誤（bug）——這個過程叫除錯（debugging）。錯誤主要分三大類：

錯誤類型什麼時候發現範例對付法
語法錯誤
Syntax Error		執行前就被直譯器攔下print(5 + )
pront(5)		看錯誤訊息指出的行數與描述
執行時錯誤
Runtime Error		程式跑到那一行才爆炸5/0
使用未定義的變數		讀 Traceback 找出爆炸點
語意錯誤
Semantic Error		不會報錯，但結果不對！該除以 100 卻忘了除準備測試案例 + print() 檢查中間值
🤖 動手問 AI

執行 pront(5) 會跳出一段錯誤訊息。先自己讀一遍、猜猜看是哪裡出了問題，再把完整錯誤訊息貼給 AI 工具，練習用它來診斷錯誤。

這段程式 pront(5) 出現錯誤，請解釋這個錯誤訊息在說什麼、為什麼會發生，先不要直接告訴我怎麼修。 如果我照著建議改完還是報錯，我可以怎麼一步步繼續排查？
⚠ 經典陷阱：input() 永遠回傳字串

num1 = input('請輸入一個數字:') 拿到的是字串！所以 num1 + num2 會變成字串串接：輸入 2 和 3，得到的是 '23' 而不是 5。這就是典型的語意錯誤——程式不會報錯，但結果不是你要的。

解法：int(input('請輸入一個數字:')) 先轉成整數再運算。

👨‍⚕️ 除錯心法（+ AI 工具）

語意錯誤最難抓，因為沒有錯誤訊息。方法是：先寫下「測試案例」（輸入 2, 3 → 預期輸出 5），執行後跟預期比對，再用 print() 印出中間值找出分歧點。看不懂錯誤訊息時，把整段 Traceback 貼給 ChatGPT / Gemini / Copilot 等 AI 工具請它診斷，是課本特別推薦的現代除錯法——但記得自己要先預測、再驗證，AI 的回答也可能出錯！
