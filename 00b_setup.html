PROLOGUE · 開場

為什麼要先把環境準備好？

要寫 Python 程式，你需要兩樣東西：一個能執行 Python 的直譯器，跟一個能寫程式的地方。這門課全部用 Jupyter Notebook —— 一種可以把說明文字、程式碼、執行結果放在同一份檔案裡的格式，非常適合邊讀邊試。

下面三條路都能達成，選一條做完就好。如果你完全沒有頭緒，直接選方法一（Colab）：不用安裝任何東西，開瀏覽器就能用。

方法安裝時間需要什麼適合誰限制
① Google Colab
推薦		0 分鐘Google 帳號、瀏覽器所有人，尤其筆電空間不夠的要有網路；turtle 畫圖不能用
② Anaconda + Jupyter10–20 分鐘約 5 GB 硬碟想離線寫、想長期用 Python 的佔空間；第一次裝比較久
③ VS Code / pip5 分鐘已裝好的 Python已經有 Python 環境的人要自己管虛擬環境
💡 可以同時裝兩套嗎？

可以，而且蠻常見的：平常用 Colab（隨開隨用、換電腦也不用重裝），第 06 章要跑 turtle 畫碎形樹的時候切到本機 Jupyter。兩者互不干擾。

PART 01 · 方法一 · 免安裝

Google Colab —— 在瀏覽器裡直接跑 Python 推薦初學者

Colab 是 Google 提供的免費雲端 Jupyter 環境。程式在 Google 的機器上跑，你只需要一個瀏覽器跟 Google 帳號。

使用步驟 5 步

① 開 colab.research.google.com，用 Google 帳號登入。
② 選「檔案 → 新增筆記本」，或直接把課程的 .ipynb 拖進去上傳。
③ 點一個程式碼儲存格，按 Shift + Enter 執行。
④ 第一次執行前，先跑下面那一格安裝套件。
⑤ 檔案會自動存進你的 Google 雲端硬碟（「Colab Notebooks」資料夾）。

每次開新的 Colab session 都要先跑這一格
# 安裝本課程需要的三個套件（Colab 已內建 matplotlib） !pip install -q pythonds3 jupyterquiz jupytercards

⚠️ Colab 的 runtime 一旦重開（閒置太久、或你自己選了「重新啟動」），裝好的套件會消失。這不是壞掉，是設計如此 —— 每次重連都重跑一次這一格就好，只要幾秒鐘。建議把它固定放在每份 notebook 的第一格。

📁 想讀自己的檔案？掛載 Google Drive
from google.colab import drive drive.mount('/content/drive')

執行後會跳出授權視窗，同意之後檔案就在 /content/drive/MyDrive/ 底下。第 08 章讀字梯字典檔時會用到類似的做法。

PART 02 · 方法二 · 本機

Anaconda + Jupyter —— 你自己的機器，離線也能寫

Anaconda 是一包「Python + 常用科學運算套件 + 環境管理工具」的懶人包。裝完之後你的電腦就有一套完整、離線可用的環境，而且 turtle 繪圖能正常運作（第 06 章遞迴會用到）。

安裝步驟 4 步

① 到 anaconda.com/download 下載對應作業系統的版本（約 1 GB，安裝後約佔 5 GB）。
② 一路下一步裝完。Windows 使用者建議勾選「Add to PATH」。
③ 打開「Anaconda Prompt」（Windows）或終端機（macOS / Linux），建立這門課專用的環境並安裝套件。
④ 啟動 Jupyter，瀏覽器會自動開啟。

終端機指令（第 ③ ④ 步）
# 建一個獨立環境，避免跟你其他專案的套件版本打架 conda create -n ds python=3.11 -y conda activate ds pip install pythonds3 jupyterquiz jupytercards matplotlib notebook # 切到放課程 notebook 的資料夾，再啟動 jupyter notebook

用 conda create 開獨立環境是好習慣：以後某個專案需要不同版本的套件時，不會把這門課的環境弄壞。之後每次要用，先 conda activate ds 再啟動 Jupyter。

PART 03 · 方法三 · 輕量

VS Code 或 pip —— 已經有 Python 的人走這條

如果你電腦裡已經有 Python 3.9 以上，不必再裝 Anaconda。

用虛擬環境 + pip
# 在課程資料夾裡建立虛擬環境 python -m venv .venv # 啟用（macOS / Linux） source .venv/bin/activate # 啟用（Windows PowerShell） .venv\Scripts\Activate.ps1 pip install pythonds3 jupyterquiz jupytercards matplotlib notebook

VS Code 使用者：安裝官方的 Python 與 Jupyter 兩個擴充套件，直接開 .ipynb 就能跑。右上角記得把 kernel 選成你剛剛建立的 .venv，這是最常見的「明明裝了卻說找不到套件」的原因。

PART 04 · 驗收

跑這一段，就知道環境好了沒

不管你選哪一條路，把下面這段貼進一個儲存格執行。沒有噴錯、而且印出四行，就代表環境沒問題。

環境驗收 snippet
import sys, matplotlib from pythonds3.basic import Stack, Queue, Deque from pythonds3.trees import BinaryTree from pythonds3.graphs import Graph from pythonds3.trees.priority_queue import PriorityQueue import jupyterquiz, jupytercards s = Stack() s.push(42) s.push(7) print('Python ', sys.version.split()[0]) print('matplotlib ', matplotlib.__version__) print('Stack pop/peek/size ->', s.pop(), s.peek(), s.size()) print('環境檢查通過，可以開始第 01 章。')
預期輸出
Python      3.13.12
matplotlib  3.10.9
Stack  pop/peek/size -> 7 42 1
環境檢查通過，可以開始第 01 章。

版本號跟你的不一樣沒關係，Python 3.9 以上都可以。重點是六行 import 全部沒噴錯，而且第三行印出 7 42 1 —— 那代表 pythonds3 的 Stack 真的能用。

PART 05 · AI 家教

把 Colab 的 Gemini 調成「家教模式」而不是「代工模式」

00A 說過：AI 要當助教，不要當代工。Colab 內建的 Gemini 提供兩個設定，剛好能把它調成家教。

Learn Mode 學習模式 推薦打開

在 Colab 右下角的 Gemini 面板裡切換到 Learn。開啟後它會改成一步一步引導你、反問你想法，而不是直接吐出完整解答。對自學來說這是加速學習迴圈，不是繞過它。

Custom Instructions 自訂指令 可貼上

在 Gemini 設定裡找到自訂指令，貼上類似這樣的一段：

我正在修一門資料結構與演算法的課，使用 Python 與 pythonds3。 請不要直接給我完整的解答程式碼。 請改成：先反問我目前的想法，指出我的錯誤在哪一行、為什麼， 並提示下一步該想什麼。只有在我明確說「給我完整答案」時才給。 回答時請一併說明這段程式的時間複雜度。

最後一行很值得加：讓它每次都順便講複雜度，你會被動地熟悉這門課最重要的思考方式。

⚠️ 提醒

AI 給的程式碼你要為它負責。作業與考試考的是你會不會，不是它會不會。把它當成隨時在旁邊的助教：可以問、可以吵、但最後那一行要自己按下去。

PART 06 · 疑難排解

常見問題

症狀原因與解法
ModuleNotFoundError:
No module named 'pythonds3'		 ① 在 Colab：runtime 重開過了，重跑安裝那一格。② 在本機：套件名稱是 pythonds3 不是 pythonds。③ VS Code：右上角的 kernel 選錯環境了。
turtle 在 Colab
畫不出東西		 這是預期的。turtle 需要本機視窗，雲端環境沒有。第 06 章的螺旋、碎形樹、Sierpinski 三角形請改用本機 Jupyter；或在 Colab 裝 ColabTurtle 這個替代套件（圖形較陽春）。本站的 06 章有等價的互動視覺化，讀網頁不受影響。
matplotlib 中文
顯示成方框		 系統缺中文字型。畫圖前指定一個有中文的字型即可，例如 plt.rcParams['font.sans-serif'] = ['Noto Sans CJK TC']；Colab 上需先安裝字型套件。
RecursionError:
maximum recursion depth		 不是環境壞掉，是遞迴沒有正確收斂。第 06 章會詳細講；先檢查基底情況有沒有寫、以及每次呼叫是不是真的讓問題變小。
作業要交 .ipynb，
Colab 怎麼下載？		 「檔案 → 下載 → 下載 .ipynb」。交出去之前建議先「執行階段 → 全部執行」確認整份從頭到尾跑得過。
一定要有 Google 帳號嗎？ 用 Colab 需要。不想用的話走方法二或方法三，完全在本機完成。
