PROLOGUE · 開場

引言：從「循序執行」到「流程控制」

日常生活中，我們無時無刻都在面對許多的選擇：要不要吃飯、要吃什麼、要不要睡覺、要不要出去玩……這些選擇，其實都是由一個又一個的邏輯判斷組成的。程式語言也是一樣——這一章，我們就來看看在 Python 裡怎麼做邏輯判斷，以及如何用布林值來做流程控制。

上一章我們學會了單一指令的基本知識，也知道程式就是一系列指令。但程式設計真正強大之處，不僅僅在於逐條執行指令！一個程式可以決定跳過某些指令、重複執行它們，或是選擇其中一組指令來執行——這些能力統稱為流程控制敘述（flow control statements），它們直接對應到流程圖中的符號。

流程圖用菱形畫出分支點（要做決定的地方），矩形畫出每一個步驟，圓角矩形則代表開始與結束。神奇的是，數學上可以證明：不管程式多複雜，通通都能只靠三種控制形式組合出來——循序執行選擇敘述重複敘述。這個看似簡單的組合技，就是結構化程式設計（structured programming）的核心理念。

結構

幾乎每一種流程控制敘述都長得像同一個套路：先寫一個稱為條件（condition）的判斷式，後面再接一段稱為子句（clause）的程式碼區塊——條件成立（True）才會執行子句。其實條件就是布林運算式，只是換了個名字登場！本章就從「怎麼用 Python 表達真與假」開始說起。

PART 01 · 布林運算式

布林運算式與比較運算子

根據不可考的統計，好像不少台中人都有「真的假的」的口頭禪——巧的是，程式語言裡也有「真的」跟「假的」，而且沒有其他的灰色地帶，這種真假值就叫做布林值（Boolean）。

正式一點來說，一個布林運算式（boolean expression）是一個運算式，其值僅為 True 或 False。True 與 False 是屬於 bool 類別的特殊值，並不是字串（注意大小寫，字首必須大寫）。

print(5 == 5) # True print(5 == 6) # False

== 屬於比較運算子（comparison operators，或稱關係運算子），其他比較運算子如下：

運算子意義
x == yx 等於 y
x != yx 不等於 y
x > yx 大於 y
x < yx 小於 y
x >= yx 大於或等於 y
x <= yx 小於或等於 y
x is yx 與 y 是同一個物件
x is not yx 與 y 不是同一個物件

這些運算子會根據給定的值評估結果為 True 或 False，因此可以在條件敘述中作為判斷依據：

print(42 == 42) # True，42 等於 42 print(42 == 42.0) # True，數值相同 print(42 == '42') # False，數字與字串永遠不同 print(2 != 3) # True print('hello' == 'Hello') # False，區分大小寫 print(42 < 100) # True print(42 >= 100) # False
⚠ 最經典的陷阱：= 與 ==

= 是指派敘述（把值存進變數），== 才是比較運算子（問「這兩個值相等嗎？」）。把 if x == 5: 誤打成 if x = 5: 是初學者最常犯的錯誤之一。

另外也沒有 =< 或 => 這種寫法——一定要寫成 <=、>=。而 is（身份運算子）檢查的是「兩個變數是否指向記憶體中同一個物件」，跟比較「值是否相等」的 == 是不同概念！

PART 02 · 布林（邏輯）運算子

布林（邏輯）運算子：and / or / not

三個布林運算子（boolean operators）：and、or、not 用來組合或反轉布林值，運算結果同樣是布林值。電腦會先計算左側運算式，再計算右側運算式。

print((4 < 5) and (5 < 6)) # True print((6 < 5) or (9 < 6)) # False print((1 == 2) or (2 == 2)) # True print(not (1==3) and (3==4)) # False

🧪 互動：and / or / not 真值表

點選 A、B 的 True / False 組合，右側即時顯示 A and B、A or B、not A 三個運算結果，並在真值表中反白目前選到的那一列：

🧪 SANDBOX
ABA and BA or Bnot A

布林運算子也有優先順序：所有數學與比較運算子執行完後，Python 會先算 not，再算 and，最後才算 or。完整的優先順序（由高到低）：

層級類別運算子
7（高）指數**
6乘法*, /, //, %
5加法+, -
4關係==, !=, <=, >=, >, <
3邏輯not
2邏輯and
1（低）邏輯or
👨‍⚕️ 好用寫法

要檢查 x 是否介於 0 與 5 之間，除了 x > 0 and x < 5，Python 也支援更簡潔的鏈式寫法 0 < x < 5——兩者完全等價！

PART 03 · 程式碼區塊

縮排：Python 如何分組程式碼區塊

Python 依照縮排（indentation）將程式碼分組成區塊（block）：從一行程式碼的縮排就能判斷區塊何時開始、何時結束。區塊有三個規則：

① 縮排增加時，區塊開始。
② 區塊中可以包含其他區塊（巢狀）。
③ 縮排減少到 0 或降至外層區塊的縮排時，該區塊結束。

name = 'Mary' password = 'swordfish' if name == 'Mary': print('你好, Mary') if password == 'swordfish': print('允許存取。') else: print('密碼錯誤。')

第一個區塊從 print('你好, Mary') 開始，包含它之後所有更深縮排的行；在它裡面又巢狀了一個只有一行的區塊 print('允許存取。')；第三個區塊同樣只有一行 print('密碼錯誤。')。

⚠ IndentationError

當同一個區塊中多行程式碼的縮排不一致時，會觸發 IndentationError。務必確保同一區塊中所有程式碼行使用相同的縮排——建議統一使用 4 個空白字元作為縮排單位。

PART 04 · 條件執行

if / elif / else：條件執行

流程控制敘述讓我們能從程式的某部分「跳」到另一部分，這稱為控制結構（control structures）。最基本的例子是 if 敘述：條件為 True 時執行主體（緊跟在 if 之後的縮排區塊）；條件為 False 時則跳過整個區塊。

Python 的 if 敘述其實是照著固定公式寫出來的複合敘述：if 關鍵字開頭，接一個會算出 True/False 的條件，再接一個冒號 :，最後從下一行開始寫一段縮排的程式碼——這幾塊拼在一起才是完整的 if 敘述：

name = 'Mary' if name == 'Alice': print('Hi, Alice.') # 條件 False，整個區塊被跳過，什麼都不印

如果想在條件為 False 時執行「另一組」程式碼，可以加上 else 子句（分支執行）：由於條件必為 True 或 False，兩個分支中必定會執行其中一個。跟人生一樣，我們不會只有兩條路！若可能性超過兩種，可以用 elif（鏈式條件）串接多個分支：「如果第一個條件為真就做這個；否則如果第二個條件為真就做那個；否則……」。

🎬 互動：逐步執行 if / elif / else

假設 name = 'Carol'、age = 3000，逐步執行下面的鏈式條件判斷，觀察 Python 如何依序檢查每個條件，直到找到第一個為 True 的分支（或全部落空後執行 else）：

name = 'Carol' age = 3000 if name == 'Alice': print('Hi, Alice.') elif age < 12: print('You are not Alice, kidd.') else: print('You are neither Alice nor a little kid.')

PART 05 · 迴圈與迭代

while 迴圈：只要條件為真就重複

小時候上學有沒有做錯事被罰寫的經驗？可能會被罰寫 100 遍「我以後不會亂丟垃圾」，一般人只能一遍一遍寫，厲害一點的可以單手拿五隻筆一次寫五遍——但如果你會使用迴圈（loop），你只需要寫一次程式，就可以叫電腦幫你寫，而且想寫幾次都行！

while 敘述讓一段程式碼反覆執行：只要條件為 True，主體就會一直被執行。while 敘述包含：while 關鍵字 → 條件 → 冒號 → 下一行開始的縮排區塊。

spam = 0 while spam < 5: print('Hello, world.') spam += 1 # 等同於 spam = spam + 1

+= 是增強指派運算子：同一個變數名稱同時出現在 = 的左右兩側的簡寫形式。while 迴圈的執行流程是：① 評估條件 → ② 若為 False，跳出迴圈，繼續下一敘述 → ③ 若為 True，執行主體後回到 ① 重新評估條件。

🎬 互動：逐步展開 while 迴圈的每一輪

完整展開 spam = 0; while spam < 5: ... 的每一輪：條件檢查 → 執行主體 → 遞增，直到條件終於變成 False 為止：

spam = 0 while spam < 5: print('Hello, world.') spam += 1

迴圈何時停止？

每一輪開始都會重新檢查條件。當 spam 遞增到 5 時，5 < 5 為 False，迴圈立刻結束——主體總共執行了 5 次。

⚠ 無窮迴圈（infinite loop）

如果忘記在迴圈主體中更新條件裡用到的變數（例如忘了寫 spam += 1），條件會永遠為 True，程式就會卡在無窮迴圈裡出不來！這是初學者最常犯的錯誤之一。若真的不小心寫出無窮迴圈，可以按 CTRL-C 送出 KeyboardInterrupt 強制中止程式。

break：立即離開迴圈

有時候需要在迴圈跑到一半時提前離開，這時可以用 break 敘述：執行流程一遇到它，就會立即跳出（離開）迴圈。搭配 while True: 建立的無限迴圈（條件永遠是 True），是很常見的寫法：

message = "" while True: message = input(prompt) if message == 'quit': break # 立即跳出迴圈 else: print(message)

當使用者輸入 'quit' 時，if 條件為 True，執行 break，流程立刻跳出迴圈；否則印出訊息，並回到 while 開頭重新檢查條件（永遠是 True）。

continue：跳過本輪剩下的部分

continue 敘述不會直接離開迴圈，而是跳過本輪迴圈剩餘的程式碼，直接回到迴圈起始位置重新檢查條件。下面的程式會從 1 數到 10，但只印出奇數：

current_number = 0 while current_number < 10: current_number += 1 if current_number % 2 == 0: continue # 偶數：跳過本輪剩下的程式碼 else: print(current_number, end=' ')

當餘數為 0（偶數）時，continue 讓 Python 忽略本輪剩下的程式碼，直接回到迴圈開頭；否則才會執行 print()。print() 的 end 參數可以改變預設的「印完自動換行」行為，這裡改成印出一個空格。

Truthy 與 Falsy 值

Python 中 0、None、空字串 ''、以及空的容器（如空串列）都被視為 falsy（等同 False），其餘所有值都被視為 truthy（等同 True）。這讓程式可以寫得更精簡：

name = '' while not name: # 等同於 while name == '' print('請輸入你的名字:') name = input() if numOfGuests: # 等同於 if numOfGuests != 0 print('請確保有足夠的空間容納所有客人。')

只要使用者輸入空字串，not name 就是 True，迴圈會持續要求輸入；用 truthy / falsy 寫法比明確比較 != '' 或 != 0 更簡潔易讀。

PART 06 · for 迴圈與 range()

for 迴圈與 range() 函數

while 迴圈會在條件為 True 時持續執行，但如果只想把程式碼區塊執行固定次數呢？可以用 for 迴圈敘述搭配 range() 函數。for i in range(5): 包含：for 關鍵字 → 變數名稱 → in 關鍵字 → 對 range() 的呼叫 → 冒號 → 縮排主體：

print('我的名字是') for i in range(5): print('Jimmy 會印五次 (' + str(i) + ')')

主體會執行 5 次：第一次 i 為 0，之後每跑完一次主體，for 敘述就把 i 加一，直到 i 增加到 range() 傳入的整數 減 1 為止。也就是說 range(5) 會讓 i 依序等於 0、1、2、3、4——共 5 個值，但不含 5！用 while 迴圈也能做到同樣的事，只是 for 迴圈更簡潔：

i = 0 while i < 5: print('Jimmy 會印五次 (' + str(i) + ')') i = i + 1

range() 的三種呼叫方式

range() 可接受最多三個用逗號分隔的整數引數：

呼叫方式意義結果
range(stop)從 0 開始，到 stop（不含）range(5) → 0,1,2,3,4
range(start, stop)從 start 開始，到 stop（不含）range(12,16) → 12,13,14,15
range(start, stop, step)間隔 step（可為負數，遞減）range(5,-1,-1) → 5,4,3,2,1,0

PART 07 · 匯入模組

匯入模組：使用標準函式庫

所有 Python 程式都能呼叫一組內建函數，例如我們已經見過的 print()、input()、len()、range()。除此之外，Python 還內建了需要另外匯入的標準函式庫（standard library）：每個模組（module）都包含一系列相關函數，需要先用 import 敘述匯入才能使用。

import 敘述由：import 關鍵字 → 模組名稱 →（選擇性）用逗號分隔的更多模組名稱 組成。例如 math 模組包含數學相關函數，random 模組包含隨機數相關函數：

import random for i in range(5): print(random.randint(1, 10))

因為 randint() 位於 random 模組中，必須用 random.randint() 這種模組名稱 + 點 + 函數名稱的寫法，才能告訴 Python 到 random 模組裡尋找這個函數。random.randint(1, 10) 會回傳一個介於 1 與 10（含兩端）之間的隨機整數。

👨‍⚕️ 小結

透過結果為 True / False 的條件，我們可以決定要執行哪些程式碼、略過哪些程式碼；也可以在迴圈中反覆執行程式碼，直到條件不成立。流程控制敘述讓我們能寫出更實用的程式——下一章我們會學到另一種流程控制的方式：撰寫自訂函數。
