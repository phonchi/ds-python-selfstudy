PART 01 · 建立字串、索引與切片

字串（string）：文字資料的序列

先想一下：你每天傳的訊息、遊戲裡的對白、成績單上的名字——在程式眼裡，這些全部都是字串。文字是程式中最常見的資料，這一章就是要學會「加工」它們：切出你要的部分、排成你要的樣子，章末還會幫「神秘島嶼」的兩位玩家排出一張漂亮的狀態表。

你已經知道可以用 + 把兩個字串串接在一起，但能做的遠不止如此！建立字串最簡單的方式，是把文字放在單引號 '...' 或雙引號 "..." 中——兩者效果完全相同：

type(''), type("") # 都是 <class 'str'>

好消息：字串其實就是一排字元組成的序列——把它想成「每個字元都有座號」，跟上一章的 list 是同一家人。所以你在 CH04 練過的招式（索引、切片、len()、in、走訪……）幾乎都能直接用在字串上。用中括號就能取出某個位置的字元：

運算式結果說明
fruit = 'banana'—建立字串物件
fruit[1]'a'索引從 0 開始，第 2 個字元
len(fruit)6字串的字元數量
fruit[-1]'a'負索引從尾端往前數，-1 是最後一個字元
fruit[-2]'n'倒數第二個字元

切片（slicing）

切片可以從原始字串中擷取子字串，語法是 [start:stop:step]：從起始位置的字元到停止位置的字元，包含 start、不包含 stop，預設間隔 step=1。若省略 start，切片從開頭開始；若省略 stop，切片延伸到結尾。

s = 'Cool-Python'
運算式結果說明
s[:5]'Cool-'同 s[0:5]
s[5:]'Python'同 s[5:len(s)]
s[::2]'Co-yhn'同 s[0:len(s):2]，每隔一個字元取一個
s[::]'Cool-Python'同 s[:]，複製整個字串
s[::-1]'nohtyP-looC'step 為負 → 反轉字串！

字串是不可變（immutable）的

字串是不可修改的物件：你不能像串列一樣用索引直接改寫其中的字元。

s = "hello" # Strings 是不可修改的物件 s[0] = 'y' # TypeError: 'str' object does not support item assignment

能做的是建立一個新字串，它是原字串的變體：

print(id(s)) # 例如 132473677310704 s = 'y' + s[1:len(s)] # 建立全新的字串物件 print(id(s)) # 例如 132473677315936 —— 是不同的物件！ print(s) # yello
⚠ 字串不可變（immutable）

s[0] = 'x' 這種寫法一定會產生 TypeError！字串的任何「修改」，本質上都是建立一個新的字串物件，再把變數這個標籤重新貼到新物件上——原本的字串完全沒有被改變。串列（list）則不同，是可變（mutable）的。

走訪與 in / not in

字串的走訪跟串列一樣，用 for 迴圈依序取出每個字元：

# 測試字串是否含有 'o' for char in s: # 從字串中取出每一個字元 if char == 'o': print("有 o") break

in 和 not in 運算子也能像用在串列上一樣用在字串，判斷一個子字串是否存在，回傳布林值：

print('Hello' in 'Hello, World') # True print('cats' not in 'cats and dogs') # False
PART 02 · 跳脫字元與原始字串

跳脫字元（escape character）

跳脫字元讓你可以在字串中使用那些原本無法直接放入的字元。跳脫字元由反斜線 \ 加上想要加入的字元組成。例如單引號字串內要放單引號，就要用 \'：Python 知道 Bob\'s 裡的單引號因為前面有反斜線，所以不是用來結束字串的引號。

跳脫字元輸出為
\'單引號
\"雙引號
\\反斜線
\tTab 鍵
\n換行（換行符號）
spam = 'Say hi to Bob\'s mother.' print("Hello there!\nHow are you?\n\tI'm doing fine.") # 輸出： # Hello there! # How are you? # I'm doing fine.

原始字串（raw string）

在字串起始引號前加上 r，就成為原始字串——它會完全忽略所有跳脫字元，字串中的反斜線一律照字面印出：

print(r'That is Alice\'s cat.') # That is Alice\'s cat.（反斜線被照印出來）

原始字串在需要輸入大量反斜線的字串時非常有用，例如 Windows 檔案路徑：

path = r'C:\Users\Al\Desktop' # 若不加 r，\U 甚至會被當成非法的萬國碼跳脫字元！
⚠ 忘記 r 的常見地雷

如果忘了加 r，'C:\new_folder\test.txt' 中的 \n 會被當成換行、\t 會被當成 Tab，整個路徑就亂掉了！這正是上面沙盒最後一個 preset 想示範的地雷，切換 raw 開關比較看看。

PART 03 · 格式化與插值

把字串放進其他字串：從 % 到 f-string

把字串放進其他字串是很常見的操作。到目前為止我們都用 + 做字串串接，但這樣寫很繁瑣：

name = 'Al'; age = 33; language = 'Python' print("\nHey! I'm " + name + ", " + str(age) + " old and I love " + language + " Programing")

舊寫法：% 格式化運算子

你在 CH01 認識的 % 是取餘數——但它其實會「變身」：只要第一個運算元是字串，% 就變成格式化運算子，像填空一樣把值塞進字串裡的洞。洞的樣子由格式說明符號決定：%d 挖給整數、%s 挖給字串、%f 挖給浮點數。結果仍然是字串，而且不必再呼叫 str()：

print("\nHey! I'm %s, %d years old and I love %s Programing"%(name,age,language)) # 類似 C 的 printf

也可以更精確地指定寬度與小數位數：% 後的數字代表總欄位寬度，用 . 分隔的第二個數字是小數部分寬度。預設數字靠右對齊，字串靠左對齊；不足寬度的部分用空格補齊：

a = 32; b = 32.145 print('a=%4d, b=%6.2f' % (a,b)) # a= 32, b= 32.15（b 被四捨五入！）

新寫法：f-string（推薦！）

Python 3.6 引入的 f-string（f 代表 formatted）功能類似字串插值，但用大括號 {} 取代 %s，並把運算式直接寫在大括號內。像原始字串一樣，f-string 在起始引號前有 f 前綴：

print(f'{a:4d},{b:6.2f}') # 效果同上，但更直覺！大括號內甚至可以放運算式，如 {age+2}

對齊方式：用 <、>、^ 分別指定靠左、靠右、置中對齊，格式規範放在變數後面，用冒號分隔：

print(f'[{a:<15d}]') # [32 ] 靠左，補到寬度 15 print(f'[{b:^9.2f}]') # [ 32.15 ] 置中，補到寬度 9

也可以在寬度前加 + 讓正數顯示 + 號（負數本來就會顯示 -），或加 0 讓補齊用 0 而不是空格（+ 的話 0 要放在 + 後面）：

print(f'[{a:+10d}]') # [ +32] print(f'[{a:+010d}]') # [+000000032]
⚠ % 是舊寫法

% 格式化運算子仍然合法、也還看得到（類似 C 語言的 printf），但現代 Python 建議一律改用 f-string：可讀性更好、能直接寫運算式，也不需要額外呼叫 str()。

神秘島嶼：幫玩家排出漂亮的狀態表

你正在做一款叫「神秘島嶼」的文字冒險遊戲，每次開場都要顯示玩家狀態。試著調整下面兩位玩家的名字與數值，看 f-string 的 {值:>8} 右對齊怎麼讓每一欄乖乖排好——不管數字是 0 還是 100，小數點永遠對齊！

📜 這張狀態表的 Python 程式碼（課本練習的參考解答之一）
def print_stats(player_name, health, experience, gold): print(f"{player_name}狀態：") print(f"生命值：{health:>8}/100") print(f"經驗值：{experience:>8}/150") print(f"金幣：{gold:>8.2f}/60.00") game_title = "神秘島嶼" print(f'歡迎來到 "{game_title}" 冒險遊戲！\n') print_stats("玩家1", 100, 0, 50.0) print("\n") print_stats("玩家2", 60, 120, 40.0)

PART 04 · 字串方法

常用字串方法：strip / upper / split…… 📎 講義外補充

除了索引、切片，字串還內建了許多實用的方法（method），可以增加或移除空白、轉換英文大小寫，或檢查字串格式是否正確。課本只在引言提到字串有這些方法、沒有逐一展開，這一節幫你把常用的整理成工具箱——不用背，需要時回來查就好：

方法說明範例結果
upper()轉成全大寫'Hello World'.upper()'HELLO WORLD'
lower()轉成全小寫'Hello World'.lower()'hello world'
isupper() / islower()檢查是否全大寫／全小寫'HELLO'.isupper()True
startswith() / endswith()檢查開頭／結尾是否符合'Hello World'.startswith('Hello')True
strip() / lstrip() / rstrip()去除頭尾／左／右空白' hi '.strip()'hi'
split(sep)依分隔符切成串列'a,b,c'.split(',')['a', 'b', 'c']
join(list)用字串把串列黏合起來'-'.join(['a','b','c'])'a-b-c'
rjust(w) / ljust(w)靠右／靠左補齊到寬度 w'7'.rjust(3,'0')'007'
center(w)置中補齊到寬度 w'hi'.center(6,'*')'**hi**'
isdigit() / isalpha() / isspace()檢查是否全為數字／字母／空白'123'.isdigit()True

🎬 互動：strip → upper → split 逐步動畫

字串方法呼叫後永遠是回傳一個新字串（或新串列），原本的字串完全不會被改變。逐步執行下面這段串接三個方法的小程式，觀察每一步變數表如何變化：

raw = ' hello world python ' step1 = raw.strip() step2 = step1.upper() step3 = step2.split() print(step3)

每一步都是新的物件：raw 從頭到尾維持原樣，step1、step2 也都沒有被後面的方法改變。這就是字串「不可變」的具體展現。

⚠ 再次提醒：字串不可變

呼叫 s.strip()、s.upper() 這類方法時，永遠是回傳一個新字串，絕不會就地修改 s 本身。想保留結果，一定要用變數接住，例如 s = s.strip()。

索引與切片

語法意義
s[i]取出索引 i 的字元（從 0 開始）
s[-i]從尾端往前數第 i 個字元
s[a:b]切出索引 a 到 b-1 的子字串（不含 b）
s[a:b:c]每隔 c 個字元切一次，c 為負則反向
s[::-1]反轉整個字串的常用寫法

跳脫字元

寫法意義
\n / \t換行／Tab 鍵
\' / \"單引號／雙引號
\\反斜線本身
r'...'原始字串，忽略所有跳脫字元

字串格式化

寫法意義提醒
%d %s %f舊式 % 格式化的整數／字串／浮點數說明符建議改用 f-string
f'{x}'f-string，大括號內可直接放運算式推薦寫法
f'{x:.2f}'浮點數取 2 位小數會四捨五入
f'{x:>10}'靠右對齊，寬度 10數字預設靠右
f'{x:^10}'置中對齊，寬度 10
f'{x:,}'加上千分位逗號
