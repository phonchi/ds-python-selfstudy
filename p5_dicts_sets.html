PROLOGUE · 引言

從「序位存取」到「鍵值對應」

之前學過的 串列 用整數索引（0, 1, 2, …）存取元素——你必須記得「第幾個位置」放了什麼。但如果我們想儲存「科目 → 成績」「姓名 → 電話」這種對應關係，用索引就很不直覺。這時候就輪到字典（dictionary）登場：一種無序集合，用來儲存 鍵–值（key–value） 對，把不可變的鍵（key）對應到特定的值（value），就像傳統紙本字典把「單字」對應到「解釋」一樣。

串列 list字典 dictionary
怎麼存取一個元素用整數索引：lst[0]用鍵：d['機率統計']
順序有序，可切片Python 3.6+ 會記住插入順序，但仍不能切片
索引/鍵的型別只能是整數任何不可變型別（str、int、tuple…）
💡 小知識：為什麼叫「字典」？

Python 內部其實是用雜湊表（Hash Table）實作字典，在其他語言常被稱為 Hash 或 Associative Array。但「雜湊」容易讓人誤會成雜湊函數本身，所以 Python 選擇了更直觀的名字——就像紙本字典把「單字」對應到「解釋」，Python 的字典把「鍵」對應到「值」。

PART 01 · 建立、存取、修改、刪除

建立字典：大括號 + 鍵值對

dict() 或空大括號 {} 可以建立一個空字典；用大括號包住多個以逗號分隔的 鍵:值 就能一次建立多筆資料。新增或更新項目一樣用方括號 []：grade['機率統計'] = 85。

🎬 互動：建立 → 新增鍵 → 查詢 → 修改 → 刪除

以成績字典 grade 為例，逐步觀察每一行程式碼如何改變字典內容：

按「單步 ▸」開始執行
grade = {} grade['機率統計'] = 85 grade['函數論'] = 80 print(grade['機率統計']) grade['機率統計'] = 90 # 鍵已存在 → 覆蓋舊值 del grade['函數論'] print(grade)

鍵已存在時

grade[key] = value 若 key 已經在字典中，會直接覆蓋舊值；若不存在，則會新增一組鍵值對。

⚠ 常見誤區

① 存取一個不存在的鍵時，直接用 grade['英文'] 會拋出 KeyError——這和串列的「超出範圍」IndexError 是同一種概念，差別只是字典用「鍵不存在」而不是「位置超出範圍」。

② 字典的鍵必須是不可變（immutable）型別，例如字串、整數或 tuple；串列（list）不能當鍵，因為串列是可變的——如果你嘗試 d[[1,2]] = 'x'，Python 會直接報 TypeError: unhashable type: 'list'。

另外，字典也不支援整數索引存取（例如 grade[0] 是不合法的，除非剛好有一個鍵叫做整數 0），也不能切片——因為字典本質上是無序集合，「第幾個」並沒有固定的意義。

PART 02 · 走訪字典

keys()、values()、items() 與 for 迴圈

字典其實會借給你三副眼鏡，讓你用不同角度看同一份資料：戴上 keys() 這副眼鏡，只看得到所有的鍵；換上 values()，只看得到所有的值；戴上 items()，鍵和值就一起入鏡，變成一組組 (鍵, 值) 元組。這三副「眼鏡」實際回傳的是 dict_keys／dict_values／dict_items 檢視物件，不是真正的 list，但一樣能直接放進 for 迴圈裡用；想要真正的串列，再包一層 list() 就好。

💡 為什麼不直接回傳 list？

如果字典有上百萬筆資料，keys() 若直接回傳一個 list，光是配置那個 list 就要耗掉一大塊記憶體。用 sys.getsizeof() 實測一百萬筆資料的字典：big_dict.keys() 只佔 40 bytes，但轉成 list(big_dict.keys()) 卻要 8,000,056 bytes！這就是為什麼 Python 選擇回傳「隨用隨產生」的檢視物件，而不是一次展開的 list。

預設情況下，直接對字典做 for k in grade: 走訪的是鍵而不是值。搭配 items() 與多重指派，可以在同一個迴圈同時取得鍵和值：

items() 每一輪實際交給你的內容

PART 03 · 成員檢查

用 in / not in 檢查鍵是否存在

如同串列，in 和 not in 運算元可以用來檢查字典。預設情況下檢查的是鍵：'機率統計' in grade 等同於 '機率統計' in grade.keys()。如果想檢查的是「值」是否存在，要明確寫成 value in grade.values()。

PART 04 · get() 方法

get() 安全存取 vs 直接用 []

每次存取前都要先 if key in d: 檢查很繁瑣。字典的 get(key, fallback) 方法接受兩個參數：要查詢的鍵，以及該鍵不存在時要回傳的備用值——永遠不會拋出 KeyError。

🧪 互動：picnic[key] vs picnic.get(key, 0)

固定字典 picnic = {'蘋果': 5, '杯子': 2}，輸入任意鍵，比較兩種存取方式：

🧪 SANDBOX
picnic[key]
picnic.get(key, 0)

因為 picnicItems 字典裡沒有 '蛋' 這個鍵，get('蛋', 0) 會回傳備用值 0；但如果不用 get()，直接寫 picnicItems['蛋'] 就會導致程式因為 KeyError 而中斷。

PART 05 · setdefault() 方法

setdefault()：只在鍵不存在時才設定值

有時候你想要「幫某個鍵設定初始值，但只在它還沒有值的時候」。傳統寫法要先判斷：

spam = {'名字': 'Pooka', '年齡': 5} if '興趣' not in spam: spam['興趣'] = '睡覺'

setdefault(key, default) 把這個模式濃縮成一行：第一個參數是要檢查的鍵，第二個參數是該鍵不存在時要設定的值；如果鍵已經存在，setdefault() 完全不會改動它。

經典範例：統計字母出現次數

計算一段文字中每個字元出現的次數，是 setdefault() 最常見的用途——確保鍵一定存在，才能安心地做 count[character] = count[character] + 1：

message = 'It was a bright cold day in April, and the clocks were striking thirteen.' count = {} for character in message: count.setdefault(character, 0) # 確保鍵存在，預設值 0 count[character] = count[character] + 1
字元出現次數說明
' '（空白）13句子中最常出現的字元
't'6
'i'6
'c'3對照課本說明：c 出現 3 次
'A'1大寫 A 只出現 1 次（區分大小寫）

（以上次數已用 Python 實際執行驗證，count 字典最終共有 23 個不同的鍵。）

PART 06 · 字典生成式

字典生成式：一行敘述建立字典

就像串列生成式，字典生成式提供了一種簡潔的語法，通常用來把一個字典映射成另一個字典。大括號搭配 key:value for … in … 的形式：

範例一：反轉鍵與值

months = {'一月': 1, '二月': 2, '三月': 3} months2 = {number:name for name, number in months.items()}
運算式結果
months2{1: '一月', 2: '二月', 3: '三月'}

範例二：把成績串列映射成平均分數

grades = {'Sue': [98, 87, 94], 'Bob': [84, 95, 91]} grades2 = {k:sum(v)/len(v) for k, v in grades.items()}
運算式結果
grades2{'Sue': 93.0, 'Bob': 90.0}

注意 grades 本身是一個「值為 list」的字典，這已經是一種巢狀結構——下一節會正式介紹更常見的巢狀型態：字典構成的串列。

PART 07 · 巢狀結構

字典構成的串列：管理一群相似的資料

如果要儲存「一群」結構相同的資料——例如通訊錄裡的每一位聯絡人都有姓名和電話——最自然的做法是建立一個串列，裡面每個元素都是一個字典。這樣就能用 for 迴圈逐一處理，也能單獨修改某一筆資料。

🎬 互動：建立通訊錄 → 更新一筆資料 → 印出全部

PART 08 · 章末案例

用字典加速費波那契數列：memoization

費波那契數列定義為 F(0)=0、F(1)=1、當 n≥2 時 F(n)=F(n-1)+F(n-2)。如果直接寫成純遞迴函數，計算 F(n) 會重複呼叫同樣的 F(k) 非常多次，呼叫次數隨 n 呈指數成長，n 稍微大一點就會慢到無法忍受。

解法是用字典把「已經算過的結果」快取（cache）起來——這個技巧叫做 memoization。下次遇到同樣的 n，直接從字典查表拿結果，不用重新計算：

def fibonacci(n, memo=None): if memo is None: memo = {} if n in memo: # 查表：算過就直接回傳 return memo[n] if n <= 1: memo[n] = n else: memo[n] = fibonacci(n-1, memo) + fibonacci(n-2, memo) return memo[n]

🎬 互動：純遞迴 vs 字典快取，呼叫次數大對決

拖動滑桿改變 n，右側即時（用 JavaScript 實際執行遞迴並計數）比較兩種寫法各呼叫了幾次函數：

函數呼叫次數（其中 — 次是查表命中）

👨‍⚕️ 結論

字典查詢把重複計算變成查表。純遞迴呼叫次數大約是 2×F(n+1)-1，隨 n 指數成長；用字典快取後，每個 n 只會真正計算一次，呼叫次數只跟 n 成正比（大約 2n-1 次）。這就是「用空間（字典）換時間」的經典範例。

PART 09 · 集合

集合（set）：只有鍵、沒有值的字典

如果你只想知道「這個東西在不在」，不需要對應的值，那就用集合。它跟字典共用同一套雜湊機制，所以成員檢查一樣是平均 $O(1)$。

集合的兩個性質：不重複（重複加入沒有作用）與無順序（不能用索引存取）。

集合的基本操作與四種集合運算
a = {"FOOL", "POOL", "POLL"} b = {"POLL", "POLE", "PALE"} a.add("POLE") a.add("FOOL") # 已經有了，不會重複加進去 print("集合會自動去重:", sorted(a)) print("成員檢查 :", "POOL" in a) print("交集 a & b :", sorted(a & b)) print("聯集 a | b :", sorted(a | b)) print("差集 a - b :", sorted(a - b)) print("對稱差 a ^ b :", sorted(a ^ b))
預期輸出
集合會自動去重: ['FOOL', 'POLE', 'POLL', 'POOL']
成員檢查      : True
交集   a & b  : ['POLL']
聯集   a | b  : ['FOOL', 'PALE', 'POLE', 'POLL', 'POOL']
差集   a - b  : ['FOOL', 'POOL']
對稱差 a ^ b  : ['FOOL', 'PALE', 'POLE', 'POOL']

建立空集合要寫 set() 而不是 {{}}——後者是空字典。四個運算子 &、|、-、^ 分別是交集、聯集、差集與對稱差，在處理「兩張圖的共同鄰居」「已走訪過哪些節點」時非常好用。

操作串列 list集合 set字典 dict
x in c$O(n)$ 逐一比對$O(1)$ 平均$O(1)$ 平均（查鍵）
允許重複是否鍵不重複
有順序（可用索引）是否保留插入順序，但不能用索引
元素限制任何東西必須可雜湊（不可變）鍵必須可雜湊
差多少？實測給你看
import timeit big_list = list(range(200000)) big_set = set(big_list) t_list = timeit.timeit(lambda: 199999 in big_list, number=200) t_set = timeit.timeit(lambda: 199999 in big_set, number=200) print(f"list 的 in（20 萬筆，200 次）: {t_list:.4f} 秒") print(f"set 的 in（20 萬筆，200 次）: {t_set:.6f} 秒") print(f"倍數: 約 {t_list / t_set:.0f} 倍")
預期輸出
list 的 in（20 萬筆，200 次）: 0.1094 秒
set  的 in（20 萬筆，200 次）: 0.000015 秒
倍數: 約 7518 倍

同樣一件事，換一個容器快了四個數量級。這不是「調校」的差別，是「能不能做」的差別——而你唯一要改的只有一個字。

⚠️ 只有「不可變」的東西能放進集合

字串、數字、元組可以；串列與字典不行，因為它們可以被就地修改，雜湊值會跟著變，集合就找不到它們了。想到「元組可以當鍵、串列不行」也是同一個原因。自訂類別要放進集合，得自己實作 __hash__——見 P9。

QUIZ · 自我檢測

自我檢測：字典與集合 隨堂自測 · 6 題

每個選項都有解說：選錯也點開看看為什麼錯。全對之後再往下翻詞彙卡。

Q1.以下程式會印出什麼？
d1 = {"a": 1, "b": 2}
d2 = d1
d2["a"] = 99
print(d1)
Q2.以下程式會印出什麼？
d = {"水果": "蘋果", "數量": 10, "價錢": 2.5}
print(list(d.keys()))
print(list(d.values()))
print(list(d.items()))
Q3.以下程式會印出什麼？
d = {"name": "Alice", "年齡": 25}
print(d.get("name"))
print(d.get("性別", "未提供"))
Q4.執行以下程式後，字典 'd' 的最終狀態為何？
d = {"a": "alpha"}
d.setdefault("a", "ALPHA")
d.setdefault("b", "beta")
d.setdefault("c", "gamma")
print(d)
Q5.執行以下程式碼後，哪一個集合會與 's' 相等？（提醒：集合是無序的。）
s = {1, 2, 3, 4}
s.add(5)
s.update([3, 6, 7])
s.remove(4)
